
## Shared laptop

- Other Mendix apps are built and run on this laptop at the same time, each in its own folder. Leave them alone.
- Use only ports {PORTS} for this app: the HTTP port, the admin port and any other port you open.
- Stop only processes you started. Before you stop a java, mxbuild, mx or Gradle process, check that its command line contains this project folder; never stop a process by name alone or because it looks left over.
