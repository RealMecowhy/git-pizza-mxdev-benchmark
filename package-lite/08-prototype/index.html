08-prototype

Git Pizza MxDev — clickable prototype

Guest screens · desktop and phone · English · USD

A clickable HTML prototype of every screen in the screen inventory (01-product-brief/ids-and-traceability.md, section 4). The app has one kind of user, the guest: there are no accounts, no sign-in and no staff screens. Kitchen, couriers and order traffic run by themselves. The prototype shows layout, navigation, texts and the mandatory states; data and simulation are faked in the browser so the journeys can be clicked end to end.

Visual reference only. When the prototype and the specification disagree, the specification wins (precedence in 00-README.md section 6.5: foundation → functional design → user stories → UI specification → prototype). Every page has a dashed ◧ Prototype button (bottom left) that switches screen states and demo data; it is not part of the app.

Prototype data

Cart, the guest's orders and simulation progress are kept in this browser's local storage (key gitpizza-proto-lite-v1). Nothing leaves the browser. Stock is fixed by the demo seed: Tiramisu Stack is sold out and jalapeños are out of stock.
